Private Cerevex plugin. Read posts/pages and apply approved title/body/meta only.

== Description ==

Cerevex connects to this site through a plugin key. Health, content read, and approved writes are HMAC-signed. Unapproved or unsigned payloads are rejected.

Distribution for MVP is a private zip. Not listed on WordPress.org.
